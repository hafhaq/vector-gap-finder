The Science Behind VoidLens

1. Hyperspherical Embedding Space (Sd−1)

Every offering is mapped onto the unit hypersphere either instantaneously via Sublinear TF-IDF + Character 4-Gram Dual-Gram Truncated SVD (LSA) or upgraded in a Web Worker to 384-D Neural Transformer embeddings (Xenova/all-MiniLM-L6-v2 running locally via WebGPU/WASM).

2. Why 2D Alone Lies — Full High-Dimensional Void Detection

Projecting 384-D space into 2D inevitably distorts distances. VoidLens displays exact Venna–Kaski Trustworthiness T(k) and Kruskal Stress-1 so you always see projection fidelity, while running all core density, topology, and void scoring directly in full Rd.

3. Exact Vietoris–Rips Persistent Homology (H₀ & H₁ TDA)

Using boundary matrix column reduction (∂₂ over ℤ₂), VoidLens detects 1-dimensional persistent topological cycles (H₁) in the cosine distance filtration. A high-persistence cycle (death − birth) proves a genuine ring of existing capabilities surrounding an empty interior cavity. The Fréchet mean on Sd−1 of the bounding cycle locates the cavity center.

4. von Mises–Fisher (vMF) KDE & Riemannian Gradient Descent

We estimate semantic probability density on Sd−1 via spherical kernel density f̂_κ(x) = (1/N) Σ exp(κ(x·vᵢ − 1)). Candidate voids (H₁ barycenters, inter-cluster SLERP bridges, and Bowyer–Watson α-shape Voronoi centers) are refined via Riemannian tangent-space gradient descent to settle into true local density valleys while remaining inside the domain support hull.

5. Structural Hole Bridge Entropy & Orthogonal Concept Inversion

Following Ronald Burt's Structural Holes theory, valuable gaps bridge distinct capability clusters (high Shannon entropy over neighbor clusters). To read an untapped vector g back into human language without a backend LLM, we compute the Modified Gram–Schmidt orthogonal residual g⊥ = g − proj_span(N(g))(g) and score cross-domain capability primitives by direct alignment, residual novelty, and low corpus saturation.
